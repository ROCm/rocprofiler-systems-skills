# Future Ideas & Notes

Quick list of ideas for future Radisha enhancements.

## Integration Ideas

### Jira Integration
- Connect to Jira via MCP server
- Create Jira issues from planning phase
- Link PRs to Jira issues automatically
- Update issue status as work progresses
- Search Jira for context when working on features

### Confluence Integration
- Publish documentation to Confluence
- Auto-generate docs from code (features, APIs, guides)
- Make documentation AI-accessible for future reference
- Use team docs as knowledge base for AI
- Onboarding documentation for new hires
- Architecture Decision Records (ADRs)

**Key benefit:** AI can reference team documentation in future sessions instead of inventing patterns

## Documentation Ideas

### Auto-generate Documentation
- Feature documentation after completing work
- API reference from code
- How-it-works guides for complex systems
- Generate diagrams automatically (architecture, flows)

### Documentation as AI Knowledge
- Published docs become part of AI context
- AI can cite team standards and patterns
- Consistent recommendations based on team docs
- New developers get same guidance as experienced ones
